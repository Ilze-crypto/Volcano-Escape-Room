Teacher setup & answer key — open before sharing

Suggested lesson: 3 minutes briefing; 30–36 minutes for the six rooms; 5 minutes final report and discussion. Ask students to justify every code and rotate roles. Pace the class at roughly five minutes per room; there is no artificial waiting lock. Fast groups complete the extension tasks after escaping.

Students need a browser and one device per group. This file works offline. Written responses are checked for completion only, not automatically marked for scientific accuracy. Ask teams to show their evidence before moving on. Answer keys are part of this file, so it is a consolidation activity rather than a secure test.
